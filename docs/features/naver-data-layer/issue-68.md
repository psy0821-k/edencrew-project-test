# Issue #68 — StockMeta 캐시 무효화 정책 수립 및 적용

## 결정

코드 로직 변경 없이 `CachingStockMetaRepository`의 클래스 docstring에 캐시 무효화 정책을
명문화한다.

### 정책 내용

- **TTL(시간 기반 만료) 없음** — 거래소명 등 메타데이터는 거래소 이전처럼 극히 드문 경우가
  아니면 바뀌지 않으므로, 시간 기반 재조회는 실익이 없다.
- **세션(앱 실행) 수명 동안 유지** — 인메모리 `Map`이라 앱을 종료하면 자연히 비워진다.
  별도의 수동 무효화 API를 두지 않는다.
- **LRU 크기 제한(`maxCacheSize`, 기본 200개)** — 무한정 커지는 것만 방지하는 목적이며,
  오래된 항목이 틀렸다고 판단해서가 아니다.
- 실패한 조회는 캐시에 남기지 않아 다음 호출에서 재시도할 수 있게 한다(기존 동작 유지).

### TTL을 도입하지 않은 이유

이 앱은 한 세션이 짧게는 수 분, 길어도 수 시간 수준인 관심종목 앱이다. 그 사이 거래소명이
바뀔 가능성은 사실상 없어, TTL 로직(만료 시각 추적, 시간 비교, 관련 테스트)을 추가해도
실사용 시나리오에서 얻는 이득이 없다. 이미 있는 LRU 크기 제한과 앱 재시작 시 자연 초기화가
사실상의 무효화 역할을 하므로, 별도 TTL은 YAGNI에 해당한다고 판단해 문서화만 진행한다.
